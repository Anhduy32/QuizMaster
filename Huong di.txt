CHUA LÀM 
1. Nơi đặt đoạn code "TẠO ĐỀ THI MỚI"
Sau này, bạn sẽ cần tạo một file tên là create_quiz.php (có thể đặt trong thư mục funsion/quiz/).

File này sẽ chứa một giao diện Form cực đẹp để người dùng nhập: Tên đề thi, Chọn môn học, Thời gian làm bài...

Khi người dùng bấm nút "Lưu đề thi", đoạn code số 1 mình gửi lúc nãy sẽ nằm ở ngay trên cùng của file này để nhận dữ liệu, móc tên username của họ và đẩy vào bảng quizzes.

2. Nơi đặt đoạn code "LÀM XONG BÀI THI"
Bạn sẽ cần tạo một file tên là submit_quiz.php hoặc take_quiz.php.

File này hiển thị các câu hỏi trắc nghiệm A, B, C, D.

Khi học sinh làm xong và bấm nút "Nộp bài", đoạn code số 2 sẽ được kích hoạt. Nó nhận số điểm mà học sinh vừa đạt được, lấy tên username của học sinh đó và lưu thành tích vào bảng quiz_history.
